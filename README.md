# 🚀 Fundamentos de la Programación

¡Bienvenido/a a este repositorio! Este espacio está diseñado para aprender, practicar y dominar los conceptos clave de los **Fundamentos de la Programación**, sirviendo como base sólida para cualquier lenguaje de programación.

---

## 🎯 Objetivos de Aprendizaje

- **Pensamiento Algorítmico:** Desarrollar la capacidad de descomponer problemas complejos en pasos lógicos simples.
- **Bases de Programación:** Dominar variables, estructuras de control (condicionales y bucles) y colecciones de datos.
- **Modularización:** Aprender a reutilizar código mediante el uso de funciones y procedimientos.
- **Buenas Prácticas:** Escribir código limpio, legible y adecuadamente documentado.

---

## 📚 Estructura de Contenidos

| Módulo | Tema | Descripción |
| :--- | :--- | :--- |
| **01** | *Lógica y Algoritmos* | Pseudocódigo, diagramas de flujo y resolución de problemas. |
| **02** | *Variables y Datos* | Tipos de datos primarios, operadores aritméticos, lógicos y relacionales. |
| **03** | *Estructuras de Control* | Toma de decisiones (`if/else`, `switch`) y ciclos/bucles (`for`, `while`). |
| **04** | *Estructuras de Datos* | Arreglos, listas, matrices y manipulación de colecciones. |
| **05** | *Funciones* | Declaración de funciones, parámetros, retornos y alcance (`scope`). |

## 🛠️️ Requisitos e Instalación

Para ejecutar y probar los códigos de este repositorio, necesitarás las siguientes herramientas:

### Prerrequisitos
*   **Editor de código:** [Visual Studio Code](https://code.visualstudio.com/) *(recomendado)*.
*   **Entorno de ejecución:** `[Python / Node.js / GCC para C++ / JDK para Java]`

### Instrucciones

1. **Clona este repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/fundamentos-programacion.git
   ```
2. **Accede al directorio del proyecto:**
   ```bash
   cd fundamentos-programacion
   ```
3. **Ejecuta un script de prueba:**
   ```bash
   # Ejemplo en Python:
   python3 modulo_01/hola_mundo.py
   ```
